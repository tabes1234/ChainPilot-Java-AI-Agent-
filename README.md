# ChainPilot-Java-AI-Agent-
ChainPilot 是一款基于 Java 与 AI Agent 技术的供应链智能决策与风险追溯平台，旨在帮助用户分析供应链运行过程中的潜在风险，并为业务处置提供辅助决策依据。平台围绕订单、库存、供应商等业务数据，结合 Java 确定性规则实现风险评分与结构化证据分析，展示风险触发条件、评分依据及数据缺口。同时，系统整合任务管理、决策建议、处置方案、执行记录和事件时间线，形成从风险识别、原因分析到决策追溯的业务闭环。平台还建设了独立的 Agent 评测中心，用于管理评测案例、查看运行结果、追踪失败原因并验证智能体的任务执行效果，为供应链业务的智能化与可解释决策提供技术支持。
